# 📝 Formato de control de cambios

Formulario web para registrar **solicitudes de cambio** en un proyecto de software: datos del solicitante, fechas, descripción del cambio, prioridad y aprobaciones.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)

## ✨ Contenido

- Campos de texto, correo y fechas para identificar la solicitud.
- Casillas de verificación y lista desplegable para clasificar el cambio.
- Estilos propios en `stilos.css`.

## 🚀 Cómo verlo

Abre `index.html` en el navegador; no necesita instalación.
